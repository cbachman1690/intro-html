# SODELO Website UX Recommendations

Based on a review of the current public site (`www.sodelomusic.org`), these updates can make the experience cleaner and more engaging:

## 1) Improve first-screen clarity
- Keep one clear headline + supporting sentence.
- Add two primary actions only: **View Events** and **Get Involved**.
- Move secondary links (press/testimonials) lower in the page hierarchy.

## 2) Strengthen event discoverability
- Present upcoming concerts in cards with:
  - date and time
  - location
  - one-sentence description
  - one clear CTA button (Tickets / Learn More)
- Keep this section above testimonials on the homepage.

## 3) Simplify conversion paths
- Use one high-contrast **Donate** button style across the whole site.
- Group "Audition" and "Volunteer" in a "Get Involved" section.
- Reduce competing calls to action in the header.

## 4) Optimize form usability
- Shorten contact form fields to essentials.
- Provide clear form purpose and expected reply turnaround.
- Add input labels, placeholders, and required-state cues.

## 5) Accessibility and readability upgrades
- Ensure color contrast is AA-compliant.
- Use semantic headings (`h1`, `h2`, `h3`) with clear hierarchy.
- Add keyboard support helpers (like a skip link).
- Keep text line-length moderate for better readability.

## 6) Trust-building content blocks
- Add a compact "impact stats" row (musicians, programs, audience).
- Add nonprofit and local mission messaging near donate section.
- Keep testimonials concise and rotate no more than 2–3 at once.
